# Dashboard Agenda Magnética

Aplicativo de gestão em React 18 e Vite.

Execute a partir da raiz do monorepo:

```bash
npm install
npm run dev:dashboard
npm run build:dashboard
```

Variáveis públicas ficam em `.env.example`. Nunca coloque chaves privadas em
variáveis `VITE_*`, pois elas são enviadas ao navegador.
